# Movie-Rating-Analysis-And-Prediction-Dashboard

## 📌 Overview

A Python-based data analysis and machine learning project that analyze movie ratings, identifies trends, and predicts ratings using relevant movie features.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Streamlit

## 🔍 Key Features

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Movie rating and genre analysis
* Data visualization
* Machine learning-based rating prediction
* Interactive dashboard

## 🎯 Learning Outcomes

* Gained practical experience in data analysis and preprocessing.
* Applied machine learning techniques for rating prediction.
* Developed an interactive dashboard to present data-driven insights.

## 🚀 How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
